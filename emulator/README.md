# NOCT Firmware Lab

Интерактивная эмуляция **настоящего C-приложения** NOCT. Состояние, экран, кнопки и MIDI-ноты обрабатываются скомпилированной прошивкой, а не копией логики на JavaScript.

1. Собери host: `sh build.sh --host --no-ble`. Windows: `tools/build-host.ps1 -NoBle` с Python, Pillow и Zig 0.13.
2. Запусти `python tools/emulator.py --port 8766`. На этом Windows-компьютере можно открыть `emulator/start.cmd`.
3. Открой `http://127.0.0.1:8766/`.

Кнопки нажимаются мышью, ручки вращаются колесом или кнопками +/−. Клавишу можно удерживать мышью. «Включить звук» запускает тестовый синтезатор браузера. Смена страниц, параметры и MIDI-журнал берутся из C-процесса. DAW Start/Stop, BPM и MIDI Clock имитируют входящий USB MIDI. Сними MIDI Clock, чтобы проверить WAIT при потере внешнего clock.

HOME возвращает контроллеры DAW. PRESET листает страницы. На остальных страницах K1–K4 редактируют показанные параметры без удержания кнопок. SEQ включает генератор, PLAY останавливает локальную генерацию. Для одновременного удержания нескольких нот можно использовать сценарии `tests/*.ctl`; host принимает `press`, `key ... down`, `spin` и `wait`.

Сервер использует только стандартную библиотеку Python и слушает 127.0.0.1. Сеть Интернет для эмуляции не нужна. Не закрывай процесс во время использования; Ctrl+C завершает сервер и C-процесс. Сохранения живут в памяти текущего C-процесса и переживают виртуальный reboot, но не завершение эмулятора.

Эмуляция не подтверждает работу USB-драйвера, загрузчика, flash или физических датчиков M-VAVE FM-1. Тестовый звук браузера не является звуком подключённого VST-инструмента.
