M-VAVE FM-1 · v0.8.0 · USB MIDI

MIDI-контроллер для FL Studio и Ableton Live

Прошивка превращает FM-1 в контроллер для DAW: клавиатура, аккорды, генератор мелодий, арпеджиатор, ручки микшера и транспорт. Встроенный синтезатор отключён — весь звук делает DAW.

Один пресет

Ноты всегда идут на канале 1, ручки и транспорт — на канале 16. Ничего не нужно переключать между DAW.

Страница = 4 ручки

PRESET листает страницы, K1–K4 меняют параметры на экране. HOME возвращает ручки в микшер DAW.

Синхронизация

Режим AUTO берёт MIDI Clock из DAW, если он есть, а без него работает от внутреннего темпа. Скрипт DAW передаёт BPM в обе стороны.

Подключение к DAW

FL Studio

  1. Папку FL Studio/NOCT из архива скопируй в Settings/Hardware/ внутри User data folder.
  2. Перезапусти FL. В MIDI Settings выбери NOCT FM-1 → Controller type NOCT FM.
  3. Назначь входу и выходу один Port number.
  4. Для синхронизации включи Send master sync на выходе.

Ableton Live 11/12

  1. Папку Ableton Live/NOCT скопируй в Remote Scripts/ в User Library.
  2. Перезапусти Live. Control Surface → NOCT, Input/Output → NOCT FM-1.
  3. Включи Track на входе и Sync на выходе.
  4. Выбери MIDI-дорожку с инструментом.
