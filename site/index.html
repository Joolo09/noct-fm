M-VAVE FM-1 · v0.8.0 · USB MIDI

MIDI controller for FL Studio and Ableton Live

This firmware turns the FM-1 into a DAW controller: keys, chords, a melody generator, an arpeggiator, mixer knobs and transport. The built-in synth is off — your DAW makes the sound.

One preset

Notes always go out on channel 1, knobs and transport on channel 16. Nothing to switch between DAWs.

Page = 4 knobs

PRESET flips pages, K1–K4 change what the screen shows. HOME returns the knobs to the DAW mixer.

Sync

AUTO follows the DAW's MIDI Clock when there is one and runs on the internal tempo otherwise. The DAW script sends BPM both ways.

Pages

PRESET goes to the next page. Generator changes take effect on the next bar.

Connecting to a DAW

FL Studio

  1. Copy the FL Studio/NOCT folder from the archive to Settings/Hardware/ inside your User data folder.
  2. Restart FL. In MIDI Settings pick NOCT FM-1 → Controller type NOCT FM.
  3. Give the input and the output the same Port number.
  4. For sync, enable Send master sync on the output.

Ableton Live 11/12

  1. Copy the Ableton Live/NOCT folder to Remote Scripts/ in your User Library.
  2. Restart Live. Control Surface → NOCT, Input/Output → NOCT FM-1.
  3. Turn on Track for the input and Sync for the output.
  4. Select a MIDI track with an instrument.
