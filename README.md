# NOCT MIDI 0.2.0

**AFTER HOURS / IN CONTROL** — MIDI-контроллер для **M-VAVE FM-1** с одним постоянным пресетом для FL Studio и Ableton Live.

**[Веб-установщик → joolo09.github.io/noct-fm](https://joolo09.github.io/noct-fm/)**

![Интерфейс настоящего C-рендерера](preview/noct-fm.gif)

## Что изменилось в 0.2

Предыдущая версия позволяла ручками менять канал клавиатуры, DAW-профиль, банк, номера CC и назначение клавиш. Это могло выглядеть как прекращение работы MIDI. Арпеджиатор по умолчанию ждал внешний clock. Движения ручек также приводили к автосохранению во flash, при котором платформа приостанавливает обработку.

Теперь доступен **один MIDI-пресет**: ноты всегда на канале 1, ручки CC20–23 на канале 16. USER-банков, смены профиля, Program Change и изменения канала с панели нет. Все клавиши остаются музыкальными при нажатии любой кнопки. Хроматическая раскладка соответствует физическим полутонам F3–G5, без аккордов на чёрных клавишах.

В 0.2 используются новые `midi_engine.c`, `midi_ui.c`, `midi_screen.c`, `midi_host.c`. Старые `engine.c`, `ui.c`, `noct_ui.c`, `host.c` сохранены как исходный материал, **в приложение не включаются**.

- Удалены автоматические записи во flash после ручек и DAW feedback. Сохранение — только явным удержанием SAVE в покое.
- Входящие MIDI-сообщения читаются ограниченной порцией; их непрерывный поток не блокирует клавиши и кнопки. USB feedback не пересылается обратно в USB.
- Внутренний синтезатор, драм-секвенсор и USB audio не входят в исполняемый MIDI-тракт. PLAY управляет DAW и не запускает барабаны.
- Арпеджиатор работает от внутреннего темпа по умолчанию, принимает все 27 клавиш, поддерживает пять порядков нот и latch. Отпускание последней клавиши и panic освобождают ноты без ожидания следующего clock.
- При смене октавы или переключении ARP удержанные клавиши корректно переозвучиваются, Note Off относится к действительно отправленной ноте.
- При пропадании внешнего clock последняя нота гасится по таймауту.
- По умолчанию используется надёжное цифровое нажатие с velocity 100, без aftertouch. Аналоговую velocity можно включить отдельно.

Полное зависание, о котором сообщил пользователь, не воспроизведено на физическом FM-1. Исправлены обнаруженные причины потери маршрутизации и убраны фоновые операции, способные прерывать MIDI; аппаратная проверка обновления необходима.

## Управление

| Орган | Действие |
| --- | --- |
| KNOB 1–4 | Всегда CC20–23 на канале 16; номера CC не меняются |
| MASTER | CC7 на канале 16; отправляет значение только после движения |
| PRESETS | Один пресет: поворот не меняет режим, канал или программу |
| SELECT | Темп арпеджиатора 40–240 BPM |
| ALGORITHM | Порядок нот ARP: Up / Down / Up-down / Random / As played |
| ARP, коротко | Включить/выключить ARP; при удержанных клавишах ноты переозвучиваются |
| Удерживать ARP + KNOB 1 | Скорость 1/4, 1/8, 1/8T, 1/16, 1/16T, 1/32 |
| Удерживать ARP + KNOB 2 | Порядок нот |
| Удерживать ARP + KNOB 3 | Диапазон 1–3 октавы |
| Удерживать ARP + KNOB 4 | Темп |
| FX | Latch арпеджиатора |
| FX + REC | Panic: завершить ноты, latch-последовательность и sustain |
| PLAY / REC | Пуск-стоп / запись в DAW |
| ENV | Sustain, пока удерживается |
| LFO | Modulation CC1, плавно вверх/вниз |
| OCT− / OCT+ | Транспозиция −3…+3 октавы |
| GLO удерживать + PLAY | Внутренний / внешний MIDI clock; текущий режим виден на экране |
| GLO удерживать + ENV | Фиксированная / измеренная velocity |
| SAVE удерживать 1 секунду | Сохранить настройки, когда нет нот, latch, sustain, playback и недавнего движения ручек |
| HOME / SEL / SEQ / EDIT / GLO | Информация об одном MIDI-пресете; клавиши не становятся редактором шагов |

Если ARP удерживался для изменения параметров, его отпускание не переключает ARP. При `EXT` включи MIDI clock от DAW; при `INT` арпеджиатор работает без синхронизации. По умолчанию 120 BPM, 1/16, Up, одна октава.

## Подключение DAW

**Обязательно переустанови скрипты после обновления с 0.1:** старый Ableton-скрипт ждал CC40–43, новый использует CC20–23. Свежий архив доступен на сайте. USB audio удалён из конфигурации устройства: после переподключения проверь выбор MIDI-порта в DAW.

**FL Studio:** папку `integrations/FL Studio/NOCT` помести в `Settings/Hardware/NOCT` внутри User data folder. Перезапусти FL, включи вход NOCT FM-1, выбери Controller type → NOCT FM. Назначь входу и выходу один Port number для feedback.

**Ableton Live 11/12:** папку `integrations/Ableton Live/NOCT` помести в `Remote Scripts/NOCT` внутри User Library. Перезапусти Live, выбери Control Surface → NOCT, Input/Output → NOCT FM-1. Включи Track для нот. Подключай порт к одной DAW за раз.

| Ручка | FL Studio | Ableton Live |
| --- | --- | --- |
| KNOB 1 / CC20 | Громкость выбранного mixer track | Громкость выбранной track |
| KNOB 2 / CC21 | Панорама выбранного mixer track | Панорама выбранной track |
| KNOB 3 / CC22 | Stereo separation выбранного mixer track | Send A |
| KNOB 4 / CC23 | Громкость выбранного channel | Send B |

CC7 — master; CC110 — play; CC111 — stop; CC112 — record; CC119 value 2 — единый MIDI-пресет. Все перечисленные CC идут на канале 16. Ноты, sustain и modulation идут на канале 1. Feedback CC116/117 показывает состояние playback/recording; CC20–23 обновляют значения ручек без повторной отправки и сохранения во flash. REC — общая запись DAW, не Session Record. Для произвольной автоматизации можно использовать ручное назначение MIDI согласно документации своей DAW; аппаратная проверка записи автоматизации ещё предстоит.

## Установка и проверки

Сайт работает через HTTPS и Web MIDI SysEx в Chrome/Edge на компьютере. Проверяются размер, SHA-256, модель и identity пакета; успешная установка подтверждается identity устройства после перезапуска. Устройство не прошивается автоматически при открытии страницы. Если пакет отсутствует или не прошёл проверку, запись заблокирована.

Сборка 0.2.0 имеет отдельный identity `FM-1_90625000200`, чтобы установщик мог отличить её от 0.1. Старые настройки формата 2 мигрируют на фиксированный канал/CC/хроматику и внутренний clock. USB MIDI — основной режим, Bluetooth и USB audio в этой сборке отсутствуют. Это экспериментальная прошивка; перед установкой сохрани данные и подготовь официальную процедуру восстановления M-VAVE.

Проверки включают все 27 клавиш, 7 октав (189 нот с парными Note Off), одновременные повороты энкодеров и игру, входящий feedback, отсутствие автосохранений, внутренний и внешний ARP, порядок нот, latch, потерю clock, перенос удержанных нот, миграцию и 10 тестов DAW-скриптов с подставными API. Реальная DAW, USB и flash на железе этими тестами не заменяются.

```sh
python tests/test_integrations.py
sh build.sh --host --no-ble
mkdir -p test-output
firmware/app/build/host/noct-usb_host tests/noct.ctl test-output
python tests/test_midi_engine.py
node tests/installer.test.mjs
```

Windows: Python 3.11+ и Pillow, Zig 0.13.0 в `tools/zig-windows-x86_64-0.13.0`; `tools/build-host.ps1 -NoBle`. Симулятор не подключается к физическому MIDI и не прошивает устройство.

Для устройства нужен Linux x86-64, JieLi pi32v2 toolchain и AC79 SDK; конфигурация сборки — `.github/workflows/firmware.yml`. Команда: `sh build.sh --no-ble --release 0.2.0`. Результат `firmware/app/build/noct-usb-0.2.0.fwsc`. Сценарий Pages использует последнюю успешную сборку с манифестом SHA-256. Исходники сайта — `site/`.

## Основа и лицензии

На основе [CTL-1](https://github.com/charlesvestal/fm1-ctl) `e181b4a1ac1510ce18ebf6e271a143c2fe364ccd`, fm1-base `b16c177a9086be955cd3e418383f2fd92c6d658b`, felucca-bsp `b4bb32ee0729595b7a30fbf239721286444eceb0`.

Код приложения, модификаций и интеграций — MPL-2.0; авторские заголовки сохранены. Лицензии платформы и сохранённых исходных материалов находятся в `LICENSE`, `upstream/LICENSING.md`, `upstream/LICENSES` и `upstream/base/`. Шрифт Terminus — SIL OFL. Sonivox EAS (Apache-2.0) сохранён в исходном дереве, но не линкуется в MIDI-сборку 0.2.

Проект независим от M-VAVE, Image-Line и Ableton. Логотипы обозначают совместимые DAW. Development identity экспериментальная и с внешними каталогами не согласована.
