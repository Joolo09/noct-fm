# NOCT FM

**AFTER HOURS / IN CONTROL** — MIDI-прошивка для **M-VAVE FM-1**, с приоритетом FL Studio и Ableton Live.

Ночная палитра, настоящий пиксельный шрифт Terminus, звёзды, движущаяся сетка горизонта и пиксельные логотипы DAW. FL Studio — янтарный; Ableton Live — мятный. PRESETS меняет профиль и запускает короткую анимацию. Экран рисуется C-кодом на родном разрешении 240×240, без загрузки картинок и выделения памяти в анимации.

![Анимация настоящего C-рендерера](preview/noct-fm.gif)

## Текущее состояние

Это **инженерная alpha**, исходники и рабочий Windows-симулятор. **Установочный `.fwsc` ещё не собран.** На этом компьютере отсутствуют Linux-среда, специализированный JieLi pi32v2 toolchain и AC79 SDK. Проверки на физическом FM-1 и внутри установленных FL Studio / Live не проводились. Симуляция USB/Bluetooth не проверяет реальные USB-дескрипторы, радиостек, задержку и flash-память устройства.

Проверено здесь:

- Сборка настоящего C-приложения с Windows-симулятором, в конфигурациях с BLE и без BLE.
- MIDI ноты и завершение удержанной ноты при смене DAW, управляющие CC, транспорт, приём обратной связи, банки и сохранение выбранной DAW после перезапуска симулятора.
- 8 тестов DAW-скриптов с подставными API: маршрутизация, обратная связь, фильтрация профиля, отсутствие устройства/посылов и дискретные параметры.
- Кадры и GIF в `preview/` получены непосредственно из C-рендерера.

## Управление

| Орган FM-1 | Действие |
| --- | --- |
| HOME | Главный экран NOCT |
| PRESETS на HOME | Влево — FL Studio, вправо — Ableton Live |
| SELECT на HOME / короткое FX | Банк четырёх ручек |
| KNOB 1–4 | Значения текущего банка, абсолютные CC 0–127 |
| ALGORITHM | Канал клавиатуры 1–15; 16 отведён управлению DAW |
| MASTER | Громкость master в DAW; отправка начинается после движения, не при загрузке |
| PLAY | Пуск / остановка |
| REC | Переключение записи arrangement / song |
| FX + REC | Panic: завершить ноты и sustain, не переключая банк |
| ENV / LFO | Sustain / modulation на канале клавиатуры |
| OCT− / OCT+ | Октава |
| SAVE | Сохранить настройки; есть сохранение после простоя |
| SEL / ARP / SEQ / EDIT / GLO | Лад, арпеджиатор, секвенсор, внутренний звук, настройки |

PRESETS на остальных страницах сохраняет исходную функцию Program Change. Внутренний звук по умолчанию выключен. Чувствительность к нажатию и channel aftertouch включены; их можно настроить в GLO → Touch. Для арпеджиатора/секвенсора по умолчанию нужен внешний MIDI Clock от DAW; иначе выбери внутренний clock в GLO.

При переключении DAW текущие ноты отпускаются, локальный транспорт останавливается, банк сбрасывается на A, фиксированная карта ручек выбранной DAW восстанавливается. Значения ручек обновляются из DAW при доступной обратной связи. Сохраняется текущий профиль, а не две независимые пользовательские карты.

## Что управляется

Все команды DAW — **MIDI channel 16**, статус `BF`. Ноты идут на выбранном канале, изначально 1.

| Банк | FL Studio | Ableton Live |
| --- | --- | --- |
| A | CC20–23: volume/pan/stereo separation выбранного mixer track, volume выбранного channel | CC40–43: volume/pan/send A/send B выбранного track |
| B | CC24–27: четыре пользовательские связи через Link to controller | CC44–47: первые четыре параметра выбранного device после Device On; в Rack это macros 1–4 |
| C | CC28–31: пользовательские связи для посылов | CC48–51: следующие четыре параметра; в Rack это macros 5–8 |
| D | CC32–35: пользовательские связи | CC52–55: пользовательские связи через MIDI Map |

FL Studio не предоставляет универсальной карты макросов для всех плагинов. Банки B/C/D оставлены для ручного назначения, подписи обозначают предложенное назначение. Их значения на FM-1 локальные: скрипт не читает произвольные связи FL. В Live банки B/C управляют параметрами выбранного устройства; для предсказуемых подписей используй Rack с восемью macros. При отсутствии параметра/посыла он пропускается.

CC7 — master, CC110 — play, CC111 — stop, CC112 — record, CC119 — выбор профиля (0 FL, 1 Live). Обратная связь: CC116 — playing, CC117 — recording, CC ручек — их значения. Feedback не отправляется повторно при неизменном значении. Не назначай служебные CC вручную. FX удержанием позволяет редактировать номера CC; изменение фиксированных номеров нарушает автоматическое соответствие скрипту до восстановления профиля.

## Подключение DAW

**FL Studio:** скопируй папку `integrations/FL Studio/NOCT` в папку пользовательских MIDI-скриптов FL Studio (`Settings/Hardware/NOCT` внутри User data folder). Перезапусти FL, включи вход `NOCT FM-1` и выбери Controller type → NOCT FM. Входу и выходу назначь один Port number для обратной связи. На FM-1 выбери FL Studio. Для банков B/C/D используй Link to controller. Движение параметров FL обновляет банк A на экране.

**Ableton Live 11/12:** скопируй папку `integrations/Ableton Live/NOCT` в `Remote Scripts/NOCT` внутри User Library. Перезапусти Live, в MIDI Settings выбери Control Surface → NOCT, Input/Output → NOCT FM-1. Включи Track для нот; Remote — для ручных назначений банка D. На FM-1 выбери Ableton Live. Для macro banks выбери Rack в Live. REC управляет общей записью, не Session Record. Live 10 / Python 2 не поддерживается.

Название порта реального устройства задано в конфигурации, но ещё не проверено на железе. Подключай порт к одной DAW за раз. Скрипты не определяют активную DAW автоматически: выбери соответствующий профиль на FM-1 после подключения. Соединение по USB — основной путь проверки; BLE реализован базой и требует отдельной проверки на железе.

Документация производителей: [FL MIDI scripting](https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/midi_scripting.htm), [установка Remote Scripts Live](https://help.ableton.com/hc/en-us/articles/209072009-Installing-third-party-remote-scripts).

## Симулятор и тесты на Windows

В текущей рабочей папке уже есть `firmware/app/build/host/noct_host.exe`. Он исполняет сценарии, не подключается к MIDI-порту компьютера и не прошивает устройство.

```powershell
.\firmware\app\build\host\noct_host.exe tests\noct.ctl preview
python tests/test_integrations.py
python tools/make-preview.py
```

Для повторной сборки нужен Python 3.11+ с Pillow и Zig 0.13.0, распакованный в `tools/zig-windows-x86_64-0.13.0`. `tools/build-host.ps1` использует bundled Python Codex, если он доступен, иначе Python из PATH. Затем:

```powershell
.\tools\build-host.ps1
.\tools\build-host.ps1 -NoBle
```

## Сборка для устройства

На **Linux x86-64** нужны Python 3.11+, Pillow, git, curl, xz, JieLi Linux toolchain и AC79 SDK. Исходники base/bsp уже находятся в `upstream/`, повторное обновление submodules для исходного архива не нужно.

```sh
python3 -m pip install Pillow
sh upstream/base/tools/get_toolchain.sh
git clone --depth 1 --branch AC79NN_SDK_V1.2.1_2023-12-13 \
  https://gitee.com/Jieli-Tech/fw-AC79_AIoT_SDK.git "$HOME/fw-AC79_AIoT_SDK"
sh build.sh --no-ble
# Ожидаемый результат: firmware/app/build/noct-usb.fwsc
sh build.sh
# Ожидаемый результат: firmware/app/build/noct.fwsc, с BLE
```

Команды сборки устройства пока не запускались до конца в поддерживаемой среде. База проверяет размеры flash/RAM, доступ к регистрам и упаковку загрузчика. Development identity `FM-1_9062500` локальная; для публичной публикации следует согласовать уникальный идентификатор. Файл симулятора `.exe` не является прошивкой.

Перед установкой требуется собрать `.fwsc`, сохранить свои данные и проверить процедуру восстановления для текущей штатной версии FM-1. NOCT использует формат и адреса хранения базы CTL-1, не умеет импортировать штатные проекты FM-1. Установка на устройство в этой работе не выполнялась. Инструменты установки и исходные сведения о восстановлении: `upstream/BUILDING.md` и `upstream/base/tools/fm1_install.py`.
